String Operations (Java)

A Java console application implementing common string algorithms using efficient DSA techniques.
Focused only on Strings & Arrays (no linked lists, trees, or graphs).

Features

Palindrome Check (Two Pointers)

First Non-Repeating Character (HashMap)

Longest Palindromic Substring (Expand Around Center)

Remove Duplicate Characters

String Rotation Check

Tech Stack

Java

IntelliJ IDEA

DSA: Strings, Arrays, HashMap, Two Pointers, Sliding Window

How to Run

Clone the repo

Open in IntelliJ

Run Main.java

Choose an operation and give input

Purpose

Strengthen DSA fundamentals

Practice clean Java coding

Learn Git & GitHub workflow
